## Tool availability

- Antigravity and Visual Studio Code were installed. Antigravity provided a scoped positioning critique without repository or credential access.
- Chrome, Brave and Safari were installed. Chrome was used for local visual inspection and browser tests.
- Gemini CLI responded to a version check. Google AI Studio opened to its public welcome page. Gemini authentication was outside the audit.
- Claude Code responded to a version check. An earlier direct check reported that it needed sign-in.
- OpenCode was present on PATH. Starting it in the shell sandbox failed because its default log directory was unwritable.
- No GitHub Copilot extension appeared in the inspected VS Code extension directory. GitHub Desktop was installed. A signed-in GitHub publishing session was not established.
- Vercel's dashboard required sign-in in both the in-app browser and the desktop Chrome profile. The Vercel CLI was not on PATH.

The public GitHub profile established the name, public email address and LinkedIn reference. LinkedIn blocked automated verification. No asset originals, source files from portfolio projects, database exports, account details or project credentials are part of this portfolio source.
